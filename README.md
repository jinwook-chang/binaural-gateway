# Gateway Signal

Gateway Signal is a binaural tone page inspired by the CIA Gateway Process documents.

## Controls

- `Beat`: The left-right frequency difference. This is the perceived binaural rhythm.
- `Carrier`: The center pitch used to create the left and right tones.
- `Volume`: Output level. Start low.

Recommended beat presets:

- `Deep Theta`: 4 Hz
- `Theta Drift`: 6 Hz
- `Gateway Calm`: 7.5 Hz
- `Low Alpha`: 8 Hz
- `Alpha Focus`: 10 Hz
- `Bright Focus`: 12 Hz
